HOW THE NUMBERS WORK
- "Update N" = a commit to GitHub, numbered in commit order.
- "build vX" = Claude's internal build number. Claude made many more builds than
  were committed, so one GitHub update contains several builds.
- Every build is listed in part B, so nothing is lost.
- Full detail for each build is in project-atlas-game-brief.md.
